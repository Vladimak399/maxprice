# План-факт и прогноз в MAX

Первая версия работает в личном диалоге с тем же MAX-ботом, который уже обрабатывает уведомления о росте закупочных цен.

## Загрузка отчёта

Отправьте боту накопительный план-факт в формате `.xlsx`. Дата факта должна быть в имени файла:

```text
факт 05.08.xlsx
факт 08.08.2026.xlsx
```

Бот:

1. скачивает вложение из MAX;
2. проверяет период и итоговый блок `Продукты`;
3. рассчитывает план на дату по периодам 1–9, 10–16, 17–23 и 24–конец месяца;
4. заменяет снимок, если файл за эту дату загружен повторно;
5. сравнивает с предыдущей загрузкой;
6. добавляет умеренную погодную поправку по Калининграду;
7. возвращает краткий прогноз.

Известная ошибка некоторых выгрузок 1С, где файл внутри архива называется `xl/SharedStrings.xml`, исправляется в памяти. Исходный файл не изменяется.

## Команды

- `План` или `/план`: факт, план на дату, прогноз месяца, необходимый темп и категории риска.
- `Данные` или `/данные`: дата последней загрузки и предыдущего снимка.

Данные разделены по MAX `user_id`: пользователь видит только файлы, которые отправил боту сам.

## Требования

- настроенный `DATABASE_URL`;
- работающий текущий MAX webhook;
- файл `.xlsx` до 25 МБ;
- дата отчёта в имени файла должна входить в период книги.

Новых переменных окружения не требуется.

## Ограничения первой версии

- обрабатывается только накопительный план-факт;
- погода пока общая для Калининграда, без координат магазинов;
- рекомендации по SKU, остаткам и min/max не входят в эту версию;
- прогноз ориентировочный и не заменяет проверку наличия товаров.
